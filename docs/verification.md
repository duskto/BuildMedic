## 如何重复运行

日常检查不请求真实模型：

```sh
uv run --extra adaptive pytest -q
uv run --extra adaptive python scripts/export_contracts.py
cd apps/web
npm ci
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

真实容器回归需先构建镜像，并把 image ID 作为 `BUILDMEDIC_TEST_DOCKER_IMAGE` 环境变量传给 pytest。未设置此变量时，这三项检查明确跳过。

真实模型页面验收会产生模型用量，须先配置 `.env`、构建前端和镜像，并启动 `uv run --extra adaptive python scripts/dev.py`，再在另一个终端执行：

```sh
cd apps/web
npm run test:live
```

可用 `BUILDMEDIC_ACCEPTANCE_URL` 指向其他受信任的本地验收地址。真实验收与日常 fixture 测试的输出目录分别为 `test-results/live` 和 `test-results/ui`。

GitHub Actions 已添加后端、Web 与 Docker 检查工作流；远端工作流尚未在本轮触发，不声称远端 CI 已通过。CI 不运行 `test:live`，不需要模型密钥。
