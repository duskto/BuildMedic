# Agent 工具诊断

创建任务时显式设置 `agent_tools=true`，或在页面勾选“启用 Agent 工具诊断”。缺省关闭，既有任务与未开启工具的幂等请求保持兼容。工具只在诊断执行阶段开放，Harness² 的策略提议与经验反思继续使用原有结构化交付。

支持本地登记案例，以及已登记并准备固定源码快照的 GitHub Job；仅日志诊断的来源不支持。DeepSeek 必须关闭思考模式；其他兼容提供方须支持原生 Chat Completions Function Calling。就绪字段表示本地配置满足前置条件，不替代提供方能力验收。

| 工具 | 平台允许的操作 |
| --- | --- |
| `read_ci_log` | 按行读取当前任务索引中的 CI / 基线日志 |
| `read_repo_file` | 按行读取固定源码，并生成对应证据引用 |
| `search_code` | 在源码索引中做字面文本检索 |
| `propose_patch` | 校验 patch 或精确编辑，保存本次 rollout 的候选 |
| `run_check` | 对本次 rollout 的候选请求固定目标或回归检查 |
| `read_check_result` | 读取基线或本次工具检查的真实退出状态、计数与日志 |
| `submit_diagnosis` | 单独交付诊断和可选候选 ID，不能指定验收结论 |

所有参数经过严格 schema、未知字段、重复 JSON 字段、路径和任务归属检查。同批请求若存在结构或权限错误，整批拒绝。修改文件前必须读取该文件；候选从原始快照生成，不叠加上次修改。源码最多 40 个文件、合计 160 KB、单文件 20 KB；被脱敏的不可交付源码不开放工具修复。读取窗口最多 100 行 / 10 KB，检索最多 20 个命中。不开放 shell、任意文件系统读取、网络请求或依赖安装。

每个 rollout 最多 6 轮模型调用、24 次工具请求、2 个不同候选、2 次新工具检查。最后一轮仅开放 `submit_diagnosis`。重复请求相同候选和检查复用此前观察记录；平台候选验收和最终独立目标 / 回归始终另起全新执行。工具结果不能替代最终验收；候选 ID、补丁字节和 hash 必须一致。

标准模式推荐 16 次调用 / 150,000 Token，自适应推荐 24 次 / 250,000 Token。这是任务总预算，包含所有 rollout、提议、反思、格式修正、工具 schema 和消息历史；不是修复保证。开启工具后最高 32 次 / 250,000 Token，另受服务端调用上限约束。创建最低调用数为标准 4、自适应 11、含经验反思的自适应 12；最低 Token 为标准 24,000、自适应 48,000。未开启工具时继续使用原来的 12 次和 100,000 Token 上限，经验反思可使用 150,000 Token。

```json
{"source":{"type":"demo","case_id":"pagination"},"mode":"standard","agent_tools":true,"limits":{"max_wall_seconds":600,"max_model_calls":16,"max_tokens":150000}}
```

任务快照的 `agent_actions` 保存工具名称、轮次、rollout、模型调用关联、执行状态和请求 / 结果产物 ID。SSE 发布 `agent.tool_started` / `agent.tool_finished`，页面策略页按实际记录展示。拒绝、取消、中断分别保留；关闭页面不取消任务。产物沿用当前会话授权。

调用使用真实 `tools` / `tool_calls` / `role=tool` 协议。助手自由文本及私有推理不进入对话归档；模型响应产物仅保存调用 ID、名称和参数 hash。通过参数校验的工具请求与实际返回单独归档；未通过参数校验时省略原始参数。可审核的诊断、策略和执行事实仍保留。

## 验证范围

脚本模型回归覆盖标准、自适应、登记远程 Docker、预算停止、取消、协议拒绝、跨任务访问、候选归属及独立执行。真实 DeepSeek + Docker 页面任务 `cd5616ccc10246449765902974b3006e` 使用 6 次调用 / 24,311 Token，9 条工具记录，其中 3 条被拒绝，完成分页案例修复。候选与最终独立检查均通过，共 8 次 Docker 检查。桌面和窄屏截图、快照位于本地忽略目录 `var/acceptance/agent-tools*`。

这次真实验收覆盖标准工具模式。带工具的 Harness² 与远程管线通过脚本模型集成检查，尚未执行相应真实模型验收；也未证明策略效果提升。完整记录见[开发验证](verification.md)。
